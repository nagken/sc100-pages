# SC-100 Concept and Reference Index

> Quick-lookup index of every term, service, and acronym you will see on the exam.

- **MCRA** - Microsoft Cybersecurity Reference Architectures - the deck
- **MCSB** - Microsoft Cloud Security Benchmark - the controls
- **CAF Secure** - Cloud Adoption Framework Secure methodology
- **WAF Security pillar** - Architectural design principles
- **Enterprise-Scale landing zone** - Reference IaC for hub-spoke + identity + policy
- **Defender XDR** - M365 native cross-domain detection + response
- **Microsoft Sentinel** - Cloud SIEM/SOAR
- **Defender for Cloud** - CSPM + CWP across clouds
- **Azure Arc** - Onboards non-Azure into Azure control plane
- **GitHub Advanced Security** - Code + secret + dependency scanning
- **Confidential Computing** - TEE-based protection of data in use
