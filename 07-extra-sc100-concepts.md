# Extra SC-100 Concepts

> Concepts that span multiple domains or appear inconsistently in the exam outline but show up on the test.

## Microsoft Cloud Security Benchmark (MCSB)

MCSB is the prescriptive control set superseding the Azure Security Benchmark. Multi-cloud (Azure, AWS, GCP). Maps to NIST 800-53, CIS, PCI. Ships as a built-in initiative in Defender for Cloud.

## Tier-0 / Tier-1 / Tier-2 model

Microsoft's privileged access model: Tier 0 = identity + control plane; Tier 1 = enterprise servers; Tier 2 = workstations. Critical for ransomware blast-radius limitation.

## Microsoft DART (Detection and Response Team) framework

MS's IR methodology: assume breach, contain, eradicate, recover, lessons learned. Aligns with NIST 800-61.

## Secure Score vs Compliance Score

Secure Score (Defender for Cloud) = technical posture. Compliance Score (Compliance Manager) = org/policy/process posture against regulations.
