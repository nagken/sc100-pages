# Hands-On Labs - SC-100

> Free-tier or trial labs you can run end-to-end in 30-60 minutes.

### 1. Diagram a target state with MCRA

Open the MCRA PowerPoint, identify each tile your customer already owns, and produce a gap assessment + 6-month roadmap.

### 2. Enable MCSB in Defender for Cloud

On a free trial Azure sub, ensure the Microsoft Cloud Security Benchmark initiative is assigned. Inspect 5 recommendations and remediate one.

### 3. Onboard a non-Azure server via Arc

Install the Connected Machine agent on a Hyper-V VM. Enable Defender for Servers Plan 2. Confirm MDE auto-installs.

### 4. Run a Sentinel-driven IR tabletop

In a Sentinel workspace, fabricate a high-severity incident via the 'Create test alerts' tool. Walk through triage, hunting, and a SOAR playbook.

### 5. Run GitHub Advanced Security on a sample repo

Fork an OSS repo, enable code scanning + secret scanning, push a fake AWS key, observe push protection blocking the commit.
